## 多级异构的高效能存储模块

该模块是一个具备多级异构结构的高效能存储模块，应支持多级的存储层，包括构建内存层、高速存储层，能够存储大规模数据并提升访问速度，支持数据迁移和预取，根据访问频率将数据在低速和高速存储层之间进行迁移，根据数据的访问模式（顺序或随机）提前加载可能访问的数据块。须涵盖如下功能：

1. 提供仿真引擎异构存储功能，兼容多种存储设备，包括：NVMe / SATA 固态盘 / ZNS SSD 等新型存储设备，提供统一访问接口。
2. 提供多层感知与调度机制，该机制能够识别数据所属存储层级，并根据访问频率、局部性对存储数据进行冷热分离，以提升访问效率和吞吐量。
3. 提供文件访问的多策略预取机制，提升系统在实时仿真、仿真回放、结果分析等多种应用场景下的存储效率。
4. 提供可配置的数据压缩与去重机制，降低存储空间和网络传输开销，提升仿真数据存储效率与资源利用率。
5. 提供 IO 调度与优先级管理功能，将仿真过程中的 I/O 操作分为实时性要求高的前台 I/O（如仿真数据落盘、检查点、实时分析）和延迟容忍型的后台 I/O（如压缩、去重、垃圾回收），保障高优先级 I/O 操作。
6. 支持仿真数据运行中采集，支撑模块能够在仿真运行过程中及时捕获多类型的数据流，包括对象属性、交互事件等。

## RDMA 分布式仿真计算模块

RDMA 分布式仿真计算模块围绕软硬件协同的 RDMA 网络体系构建低延迟、高带宽的通信能力，向仿真应用提供标准化的通信接口，兼容 RDMA 协议和非 RDMA 环境下的 TCP/IP 协议以保障部署灵活性，缩减数据传输链路中的冗余路径，提供高效网络传输与远程存储加速能力。须涵盖如下功能：

1. 提供支持 RDMA 与传统 TCP/IP 的统一通信层，通过独立协议适配器实现协议之间的无冲突切换与运行。
2. 支持聚合数据传输功能，对小规模数据包或多个并发通信流进行高效聚合。
3. 支持流量优先级机制，根据不同数据流的优先级对网络资源进行调度和分配，保证关键数据优先传输。
4. 支持 CPU 与 GPU 之间的高速直通访问功能，能够使 GPU 直接读写远程内存，避免 CPU 参与数据搬运，降低通信延迟。
5. 支持分布式节点之间数据传输的路由转发、负载均衡。

## 一致性总线内存池化仿真计算模块

该模块提供一致性互联访问、跨节点高性能数据交换等机制，实现多节点共享内存同步访问，保障数据正确一致；利用 RDMA 的分布式内存池相关技术，屏蔽底层网络细节，提升开发效率与可移植性，运用并发访问控制、数据同步等机制，保护共享资源并发访问，保障数据有序同步。须涵盖如下功能：

1. 支持 RDMA 语义特性直接远程访问内存，消除数据在内核和用户空间之间不必要的 CPU 拷贝，提升数据传输的效率。
2. 提供分布式内存池基本功能，提供封装好的 API 接口，支持用户空间直接访问远程内存区域，屏蔽底层网络细节，提升开发效率与系统可移植性。
3. 提供内存池统一命名机制，用于标识不同仿真节点间共享的内存区域。
4. 支持跨节点内存自适应分配与热数据迁移，能够支持 RDMA 本地内存与远端内存的自适应分配，动态识别热点数据并将仿真数据存放于本地内存。
5. 提供任务级与用户级内存隔离机制，对不同仿真任务使用独立的内存空间，支持多用户之间的内存访问隔离。
6. 内存池提供高可靠机制，保证在部分节点故障的情况下，系统继续可用。
