## 1.6 GPU 情况

### xfusion3

`nvidia-smi` 输出：

```text
NVIDIA-SMI has failed because it couldn't communicate with the NVIDIA driver.
no GPU
```

结论：当前服务器没有可用 NVIDIA GPU/驱动环境。

### xfusion4

`nvidia-smi`：

- Driver Version：`550.54.15`
- CUDA Version：`12.4`
- GPU0：`NVIDIA A100 80GB PCIe`, bus `00000000:AB:00.0`
- GPU1：`NVIDIA A800 80GB PCIe`, bus `00000000:E1:00.0`
- 当前有 `python` 进程占用两张 GPU，各约 23.4 GiB 显存。

`nvidia-smi topo -m`：

```text
        GPU0    GPU1    NIC0    CPU Affinity    NUMA Affinity
GPU0     X      SYS     SYS     16-31,48-63     1
GPU1    SYS      X      SYS     16-31,48-63     1
NIC0    SYS     SYS      X

NIC0: mlx5_0
```

结论：xfusion4 的 GPU 与 HCA 都在 NUMA node 1，但拓扑距离显示为 `SYS`，不是 `PIX/PXB/PHB` 级近邻。若后续实现 GPU-Direct RDMA，需要单独验证 GDRCopy/peer memory 和实际吞吐。
