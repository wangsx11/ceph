# 分布式共享数据管理系统 - 部署指南

## 系统架构

```
xfusion3 (节点A)                        xfusion4 (节点B)
├── 后端服务 (port 5000)                 ├── 后端服务 (port 5000)
└── 前端服务 (port 8080)                 └── Ceph 客户端配置

共享 Ceph 集群:
├── sync_pool (M3 跨节点同步)
├── perf_pool (M5 性能测试)
├── warm_pool (M6 温层)
└── cold_pool (M6 冷层)
```

---

## 一、前置条件

### 1.1 Ceph 集群

- 已部署 Ceph 集群（3个OSD节点）
- 配置 RDMA 网络
- 已创建 Pools: `sync_pool`, `perf_pool`, `warm_pool`, `cold_pool`

### 1.2 节点配置

- xfusion3: 已安装 Ceph
- xfusion4: 需要安装 Ceph 客户端

---

## 二、节点部署

### 2.1 xfusion4 配置 Ceph 客户端

```bash
# 1. 安装 Ceph 客户端
sudo apt install ceph-common

# 2. 复制配置文件（在 xfusion3 上执行）
sudo cp /etc/ceph/ceph.conf /tmp/
sudo cp /etc/ceph/ceph.client.admin.keyring /tmp/
sudo chmod 644 /tmp/ceph.client.admin.keyring

# 3. 传输到 xfusion4
scp /tmp/ceph.conf xfusion4:/tmp/
scp /tmp/ceph.client.admin.keyring xfusion4:/tmp/

# 4. 在 xfusion4 上移动到正确位置
ssh xfusion4
sudo mv /tmp/ceph.conf /etc/ceph/
sudo mv /tmp/ceph.client.admin.keyring /etc/ceph/
exit
```

### 2.2 同步代码到 xfusion4

```bash
# 在 xfusion3 上执行
scp ~/ceph-web/backend/app.py xfusion4:~/ceph-web/backend/
scp ~/ceph-web/dashboard/*.js xfusion4:~/ceph-web/dashboard/
```

## 三、启动服务

### 3.1 启动后端服务

```bash
# xfusion3 (节点A)
cd ~/ceph-web/backend
pkill -f "python3 app.py"
CURRENT_NODE=A PORT=5000 python3 app.py &

# xfusion4 (节点B)
cd ~/ceph-web/backend
pkill -f "python3 app.py"
CURRENT_NODE=B PORT=5000 python3 app.py &
```

### 3.2 启动前端服务

```bash
# xfusion3 上启动前端
cd ~/ceph-web/dashboard
python3 -m http.server 8080
```

## 六、重启服务

### 完整重启流程

```bash
# 1. 停止所有服务
pkill -f "python3 app.py"
pkill -f "python3 -m http.server"

# 2. 同步最新代码（如果有更新）
scp ~/ceph-web/backend/app.py xfusion4:~/ceph-web/backend/
scp ~/ceph-web/dashboard/*.js xfusion4:~/ceph-web/dashboard/

# 3. 重启后端
# xfusion3
cd ~/ceph-web/backend
CURRENT_NODE=A PORT=5000 python3 app.py &

# xfusion4
ssh xfusion4 "cd ~/ceph-web/backend && CURRENT_NODE=B PORT=5000 python3 app.py &"

# 4. 重启前端
cd ~/ceph-web/dashboard
python3 -m http.server 8080

# 5. 刷新浏览器（Ctrl+Shift+R）
```

## 十、Mock 模式（无需 Ceph/RDMA 环境）

Mock 模式通过环境变量 `USE_MOCK=true` 启用，所有性能数据由内置模拟器生成，无需连接真实 Ceph 集群或 RDMA 设备。适用于本地开发、功能演示和答辩展示。

### 10.1 Mock 模式启动

```bash
# 单节点启动（Mock 模式下无需双节点）
cd ~/ceph-web/backend
USE_MOCK=true CURRENT_NODE=A PORT=5000 python3 app.py &

# 启动前端
cd ~/ceph-web/dashboard
python3 -m http.server 8080
```

启动后终端会显示：

```
[M3] Mock 模式已启用
[M5] Mock 模式已启用
[M6] Mock 模式已启用
[Server] 启动分布式存储后端 on :5000 (Mock模式)
```

### 10.2 真实模式启动（对比）

```bash
# xfusion3 (节点A)
cd ~/ceph-web/backend
CURRENT_NODE=A PORT=5000 python3 app.py &

# xfusion4 (节点B)
ssh xfusion4 "cd ~/ceph-web/backend && CURRENT_NODE=B PORT=5000 python3 app.py &"

# 前端
cd ~/ceph-web/dashboard
python3 -m http.server 8080
```

### 10.3 Mock 数据说明

| 模块 | Mock 行为 |
|------|----------|
| M3 跨节点同步 | 内存对象存储，同步延迟 30-50μs 高斯波动 |
| M5 性能测试 | 三轮递减数据（IOPS: 105万→98万→92万），每秒推送一个数据点 |
| M6 分级存储 | 热度驱动的迁移逻辑，热层 20GB/s、温层 10GB/s、冷层 250MB/s |

### 10.4 验证 Mock 模式

```bash
# 健康检查（mock_mode 字段为 true）
curl http://127.0.0.1:5000/api/health

# 期望返回：
# {"ok": true, "mock_mode": true, "ceph_connected": false, ...}
```
